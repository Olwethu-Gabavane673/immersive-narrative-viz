# Immersive Narrative Viz

Create a fully immersive, interactive 3D WebGL developer portfolio website based on the provided CV details. The theme should bridge advanced technology with creative artistry. Design a cinematic, multi-room digital environment or interactive galaxy map where each section of the resume is a physical or abstract 3D monument. Include smooth, fluid animations utilizing modern frontend tech (like Three.js, React Three Fiber, GSAP, and Blender models). Utilize every single detail from the CV to build the landscape, matching them to custom 3D animations and visual interactions of your choice.
